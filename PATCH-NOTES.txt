WozzaWatch v6.0.2 — WozzaRead pairing + cover hotfix

- Books: artwork is now accepted only when the image alt text matches the exact chart title on that book's own LoveReading product page. Wrong artwork is rejected rather than displayed.
- Audiobooks: artwork is now accepted only from the exact Audible product image labelled for that title's cover art.
- Audiobook artwork uses a square frame so Audible's square cover art is no longer stretched/cropped into a portrait slot.
- Audiobook selector icon keeps the approved wired-earbud look, but separates the buds and raises the right bud slightly.
- Tapping a Book cover opens an Amazon UK search for that exact title.
- Tapping an Audiobook cover opens a Spotify search for that exact title.
- Existing tap, double-tap and swipe Books/Audiobooks navigation is retained.
