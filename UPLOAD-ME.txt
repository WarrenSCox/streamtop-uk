WOZZAWATCH v4.6

Quickest route:
1. Replace root update-data.mjs
2. Replace root index.html and sw.js (for visible v4.6/cache confirmation)
3. Commit changes
4. GitHub Actions > Update WozzaWatch rankings > Run workflow
5. When it succeeds, data/rankings.json will be updated automatically

Do NOT manually edit data/rankings.json.

If replacing the whole package, workflow belongs at:
.github/workflows/update-rankings.yml
