WOZZAWATCH — CLEAN MASTER BUILD (v4.0)

Upload/replace the files in this package in your GitHub repository.

IMPORTANT WORKFLOW PATH
The workflow must live at:
.github/workflows/update-rankings.yml

A visible duplicate called WORKFLOW-UPDATE-RANKINGS.yml is included only to make mobile uploads easier. If your phone hides the .github folder, upload that visible file and rename/move it in GitHub to:
.github/workflows/update-rankings.yml

After upload, changing update-data.mjs will automatically trigger the rankings workflow. You can also run "Update WozzaWatch rankings" manually once to verify it turns green.

DATA SOURCE ORDER
- Netflix Movies + TV: official Netflix UK chart first.
- Prime Movies: public Prime Video UK Top 10 movies first; JustWatch fallback if the public page cannot be parsed safely.
- Apple Movies + TV: public Apple TV UK Most Popular Now charts first; JustWatch fallback if the public page cannot be parsed safely.
- Disney / HBO / BBC / ITV and Prime TV: JustWatch fallback unless a compatible public official Movies/TV chart is available.

All source badges are clickable and identify the source used.
